第1章 岗位解码：面试官各自想考什么

1.1 “一次产品 / 二次产品”怎么理解

电力行业惯用”一次/二次”分类。迁移到交易软件：

  • 一次产品（交易主链路）：交易申报、合同管理、出清结果对接、计量结算、资金余缺分摊、信息披露——直接跑在市场规则上，错一分钱都是事故；
  • 二次产品（增值决策链）：负荷/新能源预测、价格预测、报价策略、头寸管理、偏差预警、结算核对、经营分析大屏——帮市场主体多赚钱少挨罚。

展示话术：”这两条产品线的管理打法完全不同：一次产品是’稳态研发’——流程纪律、零差错文化、规则变更的版本化管理；二次产品是’敏态研发’——快速迭代、回测验证、灰度发布。我未来团队的管理设计会按稳敏双模来建。”

（这个回答同时展示抽象能力 + 管理方法论，是管理岗面试的标准高分动作。）

1.3 三个隐形考点

  1. 安全底线意识：电网的事，安全永远大于收益。任何回答都体现”出清必须过安全校核、策略不碰断面约束”的敬畏感。

  3. 成本与经营意识：管理岗要为团队预算负责——讲 AI 必讲成本控制，讲组建必讲人力成本测算。

第4章 电力业务速修：江西现货规则 4.0

目标：20 分钟记住骨架，数字卡面试前 1 小时扫一遍。内容出自《江西省电力市场规则（试行 4.0 版·征求意见稿）》（2025 年 7 月），六个细则：注册、中长期交易、现货交易、风险防控、结算、零售。管理岗不要求背公式，但概念要能白话讲清、数字要能随口报出——这是”懂业务”的最快证明。

4.1 市场全景（30 秒讲清江西市场）

“江西市场是’中长期 + 现货 + 辅助服务 + 零售 + 绿电‘五位一体：中长期锁基本盘，年度/月度/D-2 融合交易三层滚动；现货分日前（D-1 申报、96 时段出清）和实时（运行前 15 分钟出清），用 SCUC/SCED 以’全网综合购电成本最小化’集中优化；结算按’中长期合约价 + 日前偏差 + 实时偏差‘三层日清月结；零售端售电公司用’固定+联动’或’价差分成’套餐把批发风险传导给用户；另有新能源 136 号文的机制电量作为保底，不参与市场申报出清。”

4.2 五个必须能白话解释的核心概念

  1. SCUC / SCED：安全约束机组组合 / 经济调度。目标全网综合购电成本最小化（启动费用+空载费用+电能量费用），约束是安全：负荷平衡、旋转备用、出力上下限、爬坡、线路潮流（PTDF）、断面约束、必开必停。SCUC 决定”谁开机”（滚动 3 天 144 时段），SCED 决定”开多少”（96 时段）。
  2. 节点电价 LMP = 系统电能量价格 + 阻塞价格。阻塞 = 线路潮流超限导致”低价电送不进来”；阻塞费用 = 两节点价差 × 线路潮流。用户侧初期用统一结算点电价（全市场发电侧节点电价加权平均）。
  3. 三层结算：中长期合约电量按合约价结 → 日前出清超出合约的偏差按日前节点电价结 → 实际超出日前的按实时节点电价结（用户侧对应统一结算点电价）。日清月结。
  4. 偏差回收：申报（预测）与实际偏差超允许范围、且因此获得额外收益 → 收益回收。新能源有”预测出力偏差 + 实际出力偏差”两种；用户侧看申报曲线与实际用电曲线。这是售电公司/场站最大经营风险，也是预测与决策产品的价值来源。
  5. 申报约束（燃煤机组）：3-10 段单调非递减量价曲线；每段容量 [5%, 20%] 额定；相邻段价差 [0, 10%×申报上限]；最小连续运行 24-72h、最小连续停运 6-16h。这些就是报价决策系统参数空间的硬边界。

4.3 政策热词（体现行业敏感度）

  • 136 号文：新能源上网电价市场化改革，”机制电量”保底、不参与中长期和现货申报出清结算；机制外电量进市场；过渡期规则还会完善。
  • 绿电交易：价格 = 电能量价格 + 绿色环境价值（各时段一致）；D-2 日”绿色标准能量块“挂牌；区块链存证全环节。
  • 反串谋设计：燃煤机组报价同质性检测——申报曲线特征向量欧式距离相似度过高触发考核。→ 提这个直接证明”读过原文”。
  • 二级限价：实时市场出清均价连续 7 日内累计 20 小时触及申报上限 → 次日起二级限价（一级上限的 60%）执行一周；连续 12 小时触及 → 执行三天。存煤低于 7 天的燃煤电厂按申报上限报价、不参与定价。

4.5 名词速答（15 秒一个）

  • 融合交易（D-2 日交易）：标的日前两天 48 时段电量电价，随时挂/摘牌，平台按时间优先、价格优先滚动撮合；电网代理购电只做单向增持/减持挂牌。

6.1 架构与微服务

Q：电力交易平台你会怎么设计架构？（用”一次/二次”框架答）

Q：高并发高可用怎么保证？

“无状态服务 + K8s 弹性伸缩扛申报截止前峰值；读写分离 + 缓存扛披露查询；核心链路同步落库、旁路异步化（通知/核算）；多可用区部署；对外部对接（出清结果导入、结算数据）幂等设计 + 日终对账兜底。电力系统我按调度系统标准要求：先保正确，再保快。”

Q：分布式事务怎么做？（结算场景）

“优先业务无事务化：对账 + 补偿 + 幂等重试；强一致点（结算快照生成）用本地事务 + 事件表，避免跨库分布式事务。结算宁可延迟不可差错，日终对账是最后防线。”

Q：API 规范设计？

“REST 资源建模 + 统一错误码 + 版本化（电力对接方多、版本并存是常态）；开放接口走网关做鉴权限流审计；申报接口要有最终截止时间语义：过期拒绝明确返回，不能静默接受。”

6.2 数据库与存储

Q：MySQL 调优实际做过什么？

“索引设计（覆盖索引、最左前缀）、慢查询分析、执行计划解读、大表分页优化；更大的分析场景引入 Doris 做 OLAP，MySQL 只保留交易态数据——TP/AP 分离是我做驾驶舱时的核心架构决策。”

Q：Redis / MongoDB 会吗？（弱项应对，背熟）

“Redis 生产中一直在用：热点缓存、会话、分布式锁（SETNX+过期+续期）、排行榜（ZSet），只是岗位简历上没列。MongoDB 没有生产经验，但我理解它的适用场景——申报曲线、出清结果这类异构时序文档其实适合文档存储；我有 ES 和 Doris 的分布式存储生产实践，选型方法论相通，上手成本很低。”

6.3 AI 原生应用（差异化主场）

Q：AI 原生应用和传统应用+AI 插件的区别？

“传统应用功能确定、AI 锦上添花；AI 原生是把模型的不确定性当一等工程问题来管。我的实践四个抓手：收敛行为空间（受限 DSL 代替自由 SQL）、固化语义口径（指标字典/语义视图）、预算约束（轮数/查询数上限）、确定性下沉（高频路径零 LLM 化）。迁移到报价辅助决策：AI 出建议、护栏做合规校验、人做最终确认，成熟后逐步自动化。”

Q：LLM 输出不可靠，怎么用于决策系统？

“分层兜底：生成层给建议 → 规则护栏校验（电力场景就是报价段单调非递减、段容量 5%-20%、价格在限内、申报时间窗内）→ 校验失败回传原因让模型自修 → 仍失败人工接管并留痕。全程可审计——这在电网文化里是及格线。”

Q：怎么管理比你更懂算法的人？（管理+技术桥接题，必背）

“我不需要比团队每个人更懂算法细节，但我要：会出题——把业务问题翻译成算法问题（比如’降低偏差回收’翻译成’预测分位数 + 鲁棒优化目标’）；会评审——看目标函数设置、看回测方法、看数据口径，判断结论可不可信；会要结果——算法岗考核看回测指标和上线效果，不看代码行数；会给资源——数据和算力保障，不让算法团队在脏数据上浪费时间。我做过 FastMCP Server、亲自写护栏逻辑，够跟算法工程师说’行话’，这就够了。”

6.4 算法与量化策略（JD 第 4 条正面回答）

Q：让你构建电力交易的量化决策体系，你怎么落地？

五层框架，逐层锚定江西规则： 1. 数据层：气象、96 点统调/母线负荷、新能源出力、检修、联络线、历史出清价、燃料价格（CECI）——规则的信息披露条款就是数据清单； 2. 预测层：负荷预测（相似日+时序模型）、新能源功率预测、价格预测用分位数/场景化输出（下游决策要的是风险分布）； 3. 决策层：中长期头寸管理 + 现货报价优化，目标是风险调整后收益（如 CVaR 约束），约束是规则硬边界（报价段数与单调性、段容量 5%-20%、限价 -100~1200、申报时间窗、最小运行/停运时间）；新能源场站额外优化预测偏差回收风险； 4. 执行层：96 点申报曲线自动生成、申报前合规预检、截止前多通道容错提交； 5. 风控与迭代层：回测体系（历史边界条件重放出清）、异常监控（报价偏离成本、头寸超限）、灰度与分级授权。 “管理上这是一条产品线，不是一个人的活：预测 2 人、优化决策 2 人、数据工程 1-2 人起步，我定路线、评审方案、管交付节奏。”

Q：预测不准怎么办？（鲁棒性理解）

“三个动作：预测分位数化报’区间’；决策层对误差做鲁棒优化/场景法——宁可放弃极端收益也要压住偏差回收风险（规则原文：偏差超允许范围且获额外收益会被回收）；上线后监控误差分布漂移触发再训练。量化体系 KPI 不是单日收益，是全月风险调整后收益和最大回撤。“

第7章 电力行业专项问答（12 题带答案）

管理岗被问业务，考的是”你落地会不会做偏方向”。答案锚定江西规则 4.0，引用时带”以正式版为准”。

Q1 现货市场怎么运行的？

“江西现货分日前和实时：日前 D-1 竞价，09:00 发布 96 点负荷预测等边界，10:00 前发电侧申报，调度用 SCUC/SCED 以全网综合购电成本最小化出清，17:30 前发布开机组合、96 点计划和节点电价；实时在运行前 15 分钟按超短期预测再出清。用户侧初期报量不报价，用统一结算点电价结算。” 加分：补”SCUC 滚动 144 时段、SCED 96 时段；LMP = 电能量 + 阻塞”。

Q2 中长期和现货怎么衔接？

“三层结算衔接：中长期合约电量按合约价结；日前出清与合约的偏差按日前价结；实际与日前的偏差按实时价结。中长期实质是差价锁定的财务合约，现货发现真实价格。年度净合同上限 = 装机 × 等效可用小时 × K，防止过度持仓。”

Q3 节点电价和统一结算点电价什么关系？

“发电侧按所在节点 LMP 结算（含阻塞分量）；用户侧初期用全市场发电侧节点电价加权平均（统一结算点电价）。阻塞费用单独出账——两节点价差 × 线路潮流。”

Q4 售电公司怎么赚钱、最大风险是什么？

“赚批零价差：批发侧中长期+现货组合采购，零售侧套餐卖给用户。最大风险是偏差：申报曲线与实际用电偏差超限且获额外收益会被回收；零售套餐联动条款（10%-20% 电量挂日前/实时均价）就是风险传导阀门。售电公司的核心竞争力就是预测和头寸管理——这正是研发创造收益的地方，也是我们二次产品的目标客户场景。”

Q5 新能源怎么参与市场？

“136 号文建立机制电量保底：纳入机制电量不参与申报出清结算；机制外电量可进市场，申报容量上限 = 额定 - 机制容量。场站竞价日 08:00 前报 96 点预测出力作为出力上限约束；预测偏差和实际偏差超限都有回收风险。过渡期规则还会完善——这要求我们的算法体系必须有规则参数化能力，产品不能把参数写死。”

Q6 市场风险防控产品要做什么？

“规则把风险分五类：供需、价格异常、系统安全、技术支持系统与网络安全、履约。研发视角的产品清单：价格监控告警（均价连续触及上限触发二级限价 60% 的提前预警）、头寸与偏差实时监控、报价同质性自检（避免触发反串谋考核）、申报截止倒计时与缺省申报兜底提醒。”

Q7 结算系统设计的难点？

“结算细则公式引擎化：三层结算 + 资金余缺六大费用全部参数化配置，公式版本化管理支持规则迭代；日清月结要求每日清算可重算、可追溯；电量拟合补测（集中式/分布式新能源/用户侧）需要专门的数据校核模块。结算错一分钱都是市场事故——这个模块我用调度系统的标准做，也是我管理上设’红线指标’的地方。“

Q8 绿电交易特别在哪？

“价格 = 电能量 + 绿色环境价值，环境价值各时段一致、不进峰谷分时计算；D-2 日绿色标准能量块挂牌；区块链存证全环节；售电公司绿电合同电量必须关联到零售用户。”

Q9 你了解调频辅助服务吗？

“江西调频按《湖北、江西、重庆电力调频辅助服务市场运行规则》（华中监能市场〔2025〕35 号）执行，与现货申报同步进行；现货里调频机组实际曲线与日前计划的偏差按实时价结算。我重点研究的是电能量市场，调频我理解框架，出清细节是入职后第一个要补的模块——诚实说，这也是我会排进团队学习计划的内容。”（展示诚实 + 学习路径 + 管理动作）

Q10 电价构成讲一下？

“用户电价 = 上网电价（市场化形成）+ 输配电价 + 上网环节线损 + 系统运行费（辅助服务、抽蓄容量、煤电容量电费）+ 政府性基金及附加；高耗能用户代理购电 1.5 倍；居民农业保价的损益由工商业分摊分享。”

Q11 为什么江西规则对你重要？

“我在南昌、在泰豪做过国网侧系统，江西是我家门口的市场；东华的产品如果服务江西或华中客户，我的本地规则理解能帮产品少走弯路——比如 4.0 还是征求意见稿，参数会调，产品必须参数化而不是写死，这是我读规则时就在想的产品要求。”

Q12 电力系统”安全、经济、高效”怎么排序？

“安全是约束不是目标函数——任何优化都在安全约束内求解（规则里安全校核与出清同步、必开必停、断面限值 80% 控制都是这句话的体现）。经济是目标，高效是手段。做产品和管理同样：先保证申报合规、结算零差错，再谈收益优化——我的团队红线也是按这个顺序设的。”

8.4 绩效考核体系（JD 原文考点）

Q：绩效考核怎么设计？

“先立红线，再做三维。 红线（电力软件特色，一票否决）：结算差错、申报截止迟到导致缺省申报、数据口径事故、安全合规问题——红线不参与’加减分’，碰了就是事故复盘。 三维考核（季度）： - 结果（40%）：按期交付率、线上缺陷密度、结算零差错保持、（算法岗）策略回测指标与上线效果； - 过程（30%）：评审通过率、需求返工率、风险提前暴露数、文档与规范遵循； - 成长（30%）：技术分享、带教成效、梯队补位能力。 周期与动作：季度打分 + 半年校准，绩效结果和培养计划联动——连续两期低配：先轮岗再退出，’对低绩效的仁慈是对高绩效者的不公’。 管理者自查：我自己也接受团队对管理动作的季度评分（风险清单质量、评审响应速度），管理者先被考核，制度才有公信力。”

Q：试用期考核怎么做？

“入职给 30/60/90 天三个检查点，每个点有明确交付物（如 30 天：完成规则共读并通过业务测验 + 独立修复一个带评审的缺陷）；转正答辩我亲自参加，标准提前公开。”

8.5 人才培养

Q：怎么培养人？

“四个机制，成本从低到高： ① 规则共读会（每周 30 分钟）：精读一段市场规则/一个结算案例——电力团队的’基本功训练’，我来带前三期； ② 代码评审即带教：评审意见写’为什么’，不只是’改什么’； ③ 复盘带教：让高级工程师主持复盘，练表达和归纳； ④ 梯队补位：每个关键模块必须有 backup，backup 培养纳入导师（导师绩效加分）——单点依赖是管理者的失职。”

Q：留人怎么办？（小公司/新团队没大厂钱多）

“新团队留人靠三样：赛道确定性（电力市场化是十年级别的机会，早进场是稀缺资历）、成长速度（0→1 团队里一年顶三年，我给的授权和曝光是实打实的）、成就感（产品跑在真实市场里，结算零差错是写进个人履历的战绩）。钱给不到顶尖就要把这三样给足——这也是我面候选人时承诺的东西。”

8.6 技术决策与向上管理

Q：复杂不确定环境下怎么做技术决策？（JD 原文）

“四个原则：分可逆与不可逆（架构选型慢决策留验证，可逆决策快试错）；用约束收敛不确定性（像规则限价一样把不确定参数化、边界写死）；用数据代替争论（驾驶舱语义层方案之争用’口径变更成本’判据解决）；决策留痕可审计（电网文化教的：错了复盘修正，不甩锅）。”

Q：怎么向公司汇报、管理预期？

“我的机制是’周报 + 风险清单 + 里程碑 demo‘：周报三段式（进展/风险/需要的决策），风险清单让坏消息跑在前面——重大风险我第一时间上报，从不捂；里程碑用可演示的东西代替形容词。九年实践，我的干系人从不需要’追问进度’。”

Q：和产品/销售对交付时间有分歧怎么办？

“分歧回到三件事：范围、资源、时间——三角只能动两个。销售要提前，我给选项：砍范围或加资源；不接受’又要快又要全’的模糊承诺。承诺了就按期交付，这是建立信任的唯一方式。”

8.7 管理情景题速答

情景 速答要点
核心成员提离职 先一对一听真实原因（钱/成长/关系三选一），能救则给方案并设观察期；不能救则两周内启动 backup 接管 + 招聘，离职交接制度化（文档+结对）。平时靠 8.5 的梯队机制降低单点风险
团队成员持续低绩效 先诊断（能力/意愿/岗位匹配），给 1 个季度改进计划（明确目标+每周检查），到期不达标轮岗或退出——但退出动作要体面，团队都看着
项目要延期了 提前暴露（绝不最后一周才说）→ 给选项（砍范围/加资源/延期）→ 拍板后保交付。我的记录：多客户并行无重大延期事故，靠的就是风险清单提前三周发现问题
团队和你技术分歧 上升到数据和评测口径，跑对比让结果说话；定不了的按可逆性原则我拍板我负责，复盘对事不对人
你犯错了怎么面对团队 直接认、复盘会上讲根因和改进项——管理者认错的成本远低于装，团队信任靠这个积累
加班文化怎么看 “电力交易有天然的节奏峰值（申报截止日、结算日、规则切换），关键节点冲刺我带头；但长期靠排期质量不靠加班，持续加班是我排期失职的信号”

第9章 行为面试 Top12

1. 为什么离开现在的公司？（必问，最敏感）

“天云融创待了九年，SkyForm 产品线和 AI 驾驶舱是我做起来的，感情很深。离开是两个判断：一是公司业务的市场节奏和我的职业规划出现分歧；二是我认定未来三年是电力市场化的窗口期——江西现货刚成型、规则都到 4.0 了，赛道在起飞前夜。我想把十年的管理积累、行业缘分和 AI 工程化能力放到这个赛道长期做。东华的行业布局和南昌本地场景，是我能想到的最好结合点。”

2. 为什么你适合”从 0 组建团队”这个挑战？

“三个证据：第一，我的管理经历本身就是从’管实施’到’管产品线’到’管项目群’长出来的，知道不同阶段团队要什么；第二，我主导过 AI 驾驶舱 0→1，懂新产品线从立项到交付的全链条；第三，我已经把组建方案做到了模块级——90 天路线图您可以随便挑一项往深问（8.1）。没吃过的猪肉我见过猪跑，而且画出了猪的解剖图。”

3. 你最大的管理失误是什么？

〔选真实案例，参考结构：早期项目低估某风险 → 造成什么后果 → 教训沉淀成什么机制 → 后来该机制如何避免过同类问题〕。禁忌：说”我没什么失误”或把优点包装成缺点。

4. 带团队最难的时刻？

“多人并行交付 + 核心成员波动”框架：风险清单怎么提前暴露、怎么补位、怎么向上要资源，落点”制度比个人英雄可靠”。

5. 44 岁了怎么保持技术敏感度？（年龄话题主动接住）

“用产出证明：近两年我最重的产出恰是最新技术——AI 驾驶舱智能体架构、FastMCP Server 都是 2025 年的东西。而且我的优势是新技术出来我知道它解决哪个老问题——LLM 护栏之于 SQL 注入防护、Agent 之于工作流引擎，判断力是年轻人要花时间换的，我付过学费了。”

6. 管理风格是什么样？

“机制驱动、数据说话、提前暴露。我不做救火英雄型管理者——我建机制让火少着；团队评价我大概是’要求严但讲道理，问题摆到桌面上解决’。”

7. 意向薪资？

先探结构：”方便先了解这个岗位的薪酬结构吗——固定与绩效比例、年终奖机制？”报价：现薪 +20%~30% 区间，锚点放下沿，补一句”更看重赛道长期空间，但不能低于高级管理岗的市场定价”。管理岗可主动谈”团队预算内的用人授权”。

8. 多久能到岗？

“离职手续办理中，月内可到岗”（与简历一致；背调如实说明在办流程）。

9. 接受出差吗？

“MES 时在江铃、东风二汽长期驻场。电力客户交付关键节点——申报试运行、结算核对、规则切换——该守的现场我一定守，团队长也一样。”

10. 如果方案被上级否了？

“先复述确认理解一致 → 要否决理由里的约束信息 → 有数据补数据 → 仍被否则执行并留监测点。我被否过也否过别人，机制是复盘对事不对人。”

11. 未来 3-5 年规划？

“前两年目标很具体：团队从组建到自运转，产品在江西或华中真实市场跑起来，结算零差错记录保持住，至少一个标杆客户。长期我希望成为公司在电力交易领域的技术名片，和这条产品线一起长成公司的第二增长曲线。”

12. 你还面了哪些公司？

“在看电力行业的机会，东华是最匹配的——行业布局 + 本地场景 + 岗位职责和我的积累对得上，所以我的准备也是按贵司岗位深度做的（这句话本身就是展示）。流程上我拿到 offer 会尽快给贵司明确答复。”

第10章 反向提问：问出管理水平的问题

按对象选 2-3 个（技术总监面问 T 组，老板面问 B 组，HR 面问 H 组）：

B 组（经营/组建——管理岗主打） 1. “这条产品线目前的团队和资产是什么状态——完全从 0 开始，还是有一些现有人员和代码可以接手？”（直接确认”组建”的真实含义，也帮你校准 90 天计划） 2. “这个岗位未来一年，您最希望看到的一个标志性成果是什么？” 3. “团队组建的编制和预算大概什么量级？招聘和用人上岗位有多大授权？” 4. “产品线的目标市场优先级定了吗——发电侧、售电侧还是用户侧？省内还是跨省？”（业务定位，影响团队画像）

T 组（技术/业务） 5. “量化决策体系目前是已有算法团队在迭代，还是从 0 组建？规则参数化（4.0 征求意见稿到正式版的变动）在产品里怎么管理？” 6. “结算模块现在的规则覆盖度——资金余缺六大费用都引擎化了吗？”（细节问题，直接暴露”读过细则”）

H 组（流程） 7. “面试流程还有几轮？团队更看重候选人的哪类特质？” 8. “这个岗位的考核周期和方式是怎么设的？”（呼应你自己要定考核，显专业）

禁忌问题：加班多不多、能不能远程、公司裁员吗——初面阶段一概不问。

第12章 薪资与流程建议

  1. 信息收集：面试前查东华软件（002065）财报中电力/智慧产业板块收入占比与增速——谈薪和反向提问都用得上。
  2. 报价策略：管理岗薪酬 = 固定 + 绩效 + 可能的项目奖/团队奖。报价给区间（现薪 +20%~30%），锚点放下沿；主动问”绩效怎么评、团队预算怎么管”——你未来就是定绩效和管预算的人，问题本身就是展示。
  3. 多轮节奏：HR 初面（60 秒自我介绍 + 离职原因 + 薪资）→ 技术/总监面（第 5/6 章主场 + 8.6 技术决策）→ 总经理面（第 8 章组建落地 + 反向提问 B 组）→ 可能的述职面（可主动提出”我准备了一份电力交易产品线的组建方案，欢迎指正”——把 8.1 讲成 10 页 PPT，把面试变成工作汇报）。
  4. offer 判断重点：团队授权（招聘权、技术路线权、绩效话语权）、产品线盈亏定位、规则变化的响应资源。
